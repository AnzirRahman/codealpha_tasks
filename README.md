--------------------------------------

* Task description: Train a machine learning model to classify iris flowers based on their measurements.
* Solution: `iris-dataset-classification.ipynb`

**Task 2: Unemployment Analysis with Python**
---------------------------------------------

* Task description: Analyze the unemployment rate using Python.
* Solution: `unemployment-analysis.ipynb`

**Task 3: Car Price Prediction with Machine Learning**
------------------------------------------------------

* Task description: Train a car price prediction model using machine learning.
* Solution: `car-price-prediction.ipynb`

**Task 4: Sales Prediction using Python**
-------------------------------------------

* Task description: Predict sales using Python and machine learning.
* Solution: `sale-prediction.ipynb`
